# 机械臂轨迹修改操作说明

## 1. 文档范围

本文以 `statsh_put_L` 为例，说明如何修改机械臂轨迹。该轨迹定义在：

```text
source/task/auto_get_task/auto_traj_data.cpp
```

当前 `statsh_put_L` 共 7 个节点，代码中的累计时间为 9 秒。

注意：`statsh_put_L` 目前没有被遥控器的 `E` 键直接调用。遥控器 `E` 键第三次选择“右前”时，实际调用的是 `statsh_put_L_A`。如果只修改 `statsh_put_L`，遥控器运行现有映射时不会产生变化。

---

## 2. 轨迹节点格式

每个节点的格式如下：

```cpp
{
    {
        {J1角度, J1速度},
        {J2角度, J2速度},
        {J3角度, J3速度},
        {J4角度, J4速度},
        {J5角度, J5速度},
        {J6角度, J6速度},
    },
    节点持续时间_ms,
    夹爪状态
},
```

含义：

| 字段 | 单位 | 说明 |
|---|---:|---|
| 角度 | rad | 目标关节角度，正负号表示方向 |
| 速度 | rad/s | 该节点下发给关节的位置速度 |
| 节点持续时间 | ms | 经过该时间后切换到下一个节点 |
| 夹爪状态 | 枚举 | `GRIPPER_OPEN_MODE` 或 `GRIPPER_CLOSE_MODE` |

数组顺序是 `J1~J6`。代码数组下标是 `0~5`，因此 `q[0]` 是 J1，不是 J0。

常用角度换算：

```text
0.1 rad 约等于 5.7°
0.4 rad 约等于 22.9°
0.5 rad 约等于 28.6°
0.75 rad 约等于 43.0°
Pi / 2 约等于 90°
```

## 4. 修改单个节点的方法

例如，要把节点 1 的 J1 从 `0.75 rad` 改成 `0.90 rad`，只修改对应的一项：

```cpp
// 修改前
{0.75f, 1.5f},

// 修改后
{0.90f, 1.0f},
```

其中：

- `0.90f` 是 J1 的目标角度；
- `1.0f` 是 J1 到达目标时使用的速度。

如果只想改变目标位置，不想改变速度，只修改第一个数：

```cpp
{0.90f, 1.5f},
```

如果只想让运动变慢，只修改第二个数：

```cpp
{0.75f, 0.5f},
```

## 5. 增加、删除和调整节点

### 5.1 增加节点

在两个节点之间复制一个完整节点，然后修改角度、速度、时间和夹爪状态。例如：

```cpp
{
    {
        {0.75f, 0.5f},
        {0.2f, 0.5f},
        {0.2f, 0.5f},
        {0, 0.5f},
        {-0.5f, 0.5f},
        {0, 0.5f}
    },
    1500,
    GRIPPER_OPEN_MODE
},
```

数组底部的长度计算使用 `sizeof`，所以增加节点后不需要手动修改 `statsh_put_L_size`。

### 5.2 删除节点

删除整个节点，包括：

1. 六个关节的角度速度；
2. 节点时间；
3. 夹爪状态。

不能只删除某一个关节行，否则数组结构会错误。

### 5.3 调整节点停留时间

例如把节点 3 从 2 秒改成 3 秒：

```cpp
// 修改前
2000,

// 修改后
3000,
```

节点时间越长，机械臂在该节点保持的时间越长。当前轨迹执行器按节点切换目标，不对节点之间的角度做软件插值；实际运动过程由电机的位置速度控制完成。

## 6. 让遥控器实际执行 statsh_put_L

当前遥控器 `E` 键的轨迹映射在：

```text
source/task/Referee_Task/arm_referee.c
```

轨迹选择最终在：

```text
source/task/auto_get_task/auto_get_task.cpp
```

当前右前分支是：

```cpp
case CMD_AUTO_GET_RIGHT_FRONT:
    Auto_Switch_Group(statsh_put_L_A, statsh_put_L_A_size);
    break;
```

如果希望右前分支改为执行 `statsh_put_L`，修改为：

```cpp
case CMD_AUTO_GET_RIGHT_FRONT:
    Auto_Switch_Group(statsh_put_L, statsh_put_L_size);
    break;
```

`statsh_put_L` 和 `statsh_put_L_size` 已经在 `auto_traj_data.h` 中声明，在 `auto_traj_data.cpp` 中定义，因此通常不需要新增声明。

修改映射后，按遥控器 `E` 键循环到右前位置时，才会执行本文列出的 7 个节点。

## 7. 推荐的现场调试步骤

### 步骤 1：确认修改对象

先确认要改的是：

- `statsh_put_L`：本文档对应的左侧存矿轨迹；或
- `statsh_put_L_A`：当前遥控器 `E` 键右前分支实际执行的轨迹；或
- 其他轨迹数组。

不要只根据变量名判断，必须同时检查 `auto_get_task.cpp` 中的 `Auto_Switch_Group()` 映射。

### 步骤 2：备份原始数据

复制原节点数据，或使用版本控制保存修改前状态。每次只修改一个节点或一个关节，便于定位问题。

### 步骤 3：先降低速度

首次测试建议将运动速度设为 `0.3~0.5 rad/s`，例如：

```cpp
{0.75f, 0.5f}
```

确认方向和机械结构安全后，再逐步提高速度。

### 步骤 4：单独测试一个节点

先只保留或重点测试目标节点，确认：

- J1~J6 顺序没有写错；
- 正负方向正确；
- 角度没有超出机械限位；
- J5、J6 等容易碰撞的关节不会干涉；
- 夹爪动作时机正确。

### 步骤 5：逐步恢复完整轨迹

按节点 0、1、2……的顺序测试。每个节点确认完成后再测试下一个节点。

### 步骤 6：确认遥控器映射

如果修改后遥控器动作没有变化，优先检查：

1. 修改的数组是否就是遥控器当前调用的数组；
2. `Arm_Current_Control_Mode` 是否进入 `Arm_Auto_Mode`；
3. `auto_key_cmd_exec()` 是否收到对应命令；
4. `auto_traj_data.cpp` 是否重新编译并链接。

### 步骤 7：编译检查

在工程根目录执行：

```powershell
cmake --build build
```

确认没有数组初始化、符号声明或类型错误后，再烧录测试。

## 8. 安全注意事项

- 轨迹角度是弧度，不要把 `90` 直接写成角度值；应写成 `Pi / 2` 或约 `1.5708f`。
- 修改 J1 时先使用小角度变化，例如每次不超过 `0.2 rad`。
- 不要在机械臂附近直接高速测试。
- 含有负角度的 J2、J5 节点要特别检查机械干涉。
- 夹爪闭合节点必须确认目标物体和夹爪位置已经对齐。
- 现场测试时准备急停、断电或禁用电机的方法。
- 发现方向相反时，先确认当前轨迹坐标与 `joint_custom_polarity_map` 的关系，不要直接把所有节点角度取反。
