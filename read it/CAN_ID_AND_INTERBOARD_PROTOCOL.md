# 板二 CAN ID 与板间协议

所有总线使用经典 CAN 数据帧、11 位标准 ID、1 Mbit/s；FDCAN 外设在经典模式运行。板二不得把电机挂到 FDCAN3。

| 总线 | 设备 | 发送 ID | 接收/反馈 ID | 备注 |
| --- | --- | --- | --- | --- |
| FDCAN1 | DJI 摩擦轮左/右/下 + DJI yaw | `0x200` | `0x201` / `0x202` / `0x203` / `0x204` | `0x200` 四槽位电流组帧，前三槽摩擦轮，第四槽 yaw。 |
| FDCAN2 | DM4310 pitch | `0x010` 基础；位置帧 `0x110` | `0x011` | 从机/主机 ID 为暂定值，台架确认后才能固化。 |
| FDCAN3 | 板一 → 板二命令 | — | `0x301` | 仅板间通信。 |
| FDCAN3 | 板二 → 板一状态 | `0x302` | — | 仅板间通信。 |

## 板一到板二：`0x301`

8 字节，小端序，最后一字节为 CRC-8：

| 字节 | 字段 | 说明 |
| --- | --- | --- |
| 0 | `sequence` | 单调递增的 `uint8_t`，允许自然回绕。 |
| 1 | `command_flags` | bit0：摩擦轮使能；bit1：云台使能；其余必须为 0。 |
| 2 | `friction_speed_deci_mps` | 0.1 m/s 单位；0 使用 13.0 m/s 名义值，其余会被限定到 12–14 m/s。 |
| 3 | `yaw_rate_dps` | 有符号 deg/s。 |
| 4–5 | `pitch_target_cdeg` | 有符号 0.01 deg，小端序。 |
| 6 | `allowed_42mm_rounds` | 临时许可弹数；0 必须禁止发射。 |
| 7 | `crc8` | 对字节 0–6 调用仓库 `Get_CRC8_Check_Sum(..., 0xFF)`。 |

## 板二到板一：`0x302`

| 字节 | 字段 | 说明 |
| --- | --- | --- |
| 0 | `sequence` | 板二状态序号。 |
| 1 | `shoot_state` | 0：SAFE；1：SPINUP；2：READY；3：FAULT。 |
| 2 | `status_flags` | bit0 轮组就绪；bit1 发射许可；bit2 裁判在线；bit3 SBUS 在线；bit4 板间在线；bit5 看门狗故障。 |
| 3 | `packet_loss_percent` | 最近已完成统计窗口与当前窗口的较坏值。 |
| 4–5 | `shooter_heat` | 42 mm 热量，小端序。 |
| 6 | `allowed_42mm_rounds` | 板二当前采用的许可弹数。 |
| 7 | `crc8` | 对字节 0–6 计算 CRC-8，初值 `0xFF`。 |

## 丢包和故障语义

- 板二只接受 CRC 正确的 `0x301`；100 ms 没有有效命令则离线；
- 先收满至少一个 100 包统计窗口，才允许链路通过发射门；
- 已完成窗口或正在累计窗口的丢包率达到 5% 即关闭发射许可；
- 序号重复不作为“丢 255 包”处理；序号异常回跳会形成高丢包，须重新建立健康窗口；
- 板一必须在其工程中实现相同 CRC、ID、周期和许可弹量语义，且不能把电机帧混入 FDCAN3。

协议字段的赛事含义、特别是 `allowed_42mm_rounds` 的官方来源尚待确认，见 [README_OPEN_ISSUES.md](README_OPEN_ISSUES.md)。
