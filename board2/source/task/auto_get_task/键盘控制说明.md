# 键盘控制说明

## 一、底盘控制（`chassis_drive.c` — `Chassis_Keyboard_Mode`）

| 按键 | 功能 |
|------|------|
| **W** | 前进 |
| **S** | 后退 |
| **A** | 左移 |
| **D** | 右移 |
| **Shift + WASD** | 平移速度变为原来的 30%（减速） |
| **鼠标 X 轴** | 修改目标 yaw 角（控制底盘旋转方向） |
| **Ctrl + 任意键** | 屏蔽 WASD 底盘平移，留给上层功能键 |

> **方向状态说明**：
> - **Front 模式**（默认）：W=前，S=后，A=左，D=右
> - **Right 模式**：方向盘转向右侧，WASD 映射相应旋转

---

## 二、按键触发命令（`referee_keyboard.c` — `Referee_OnKeyboardKeyPressed`）

| 按键 | 功能 |
|------|------|
| **B** | 切换 遥控器(DBUS) / 键盘(Keyboard) 控制模式 |
| **C** | 切换 底盘普通(Normal) / 抬升(Rising) 模式 |
| **R** | 切换抬升行为：单级抬升 ↔ 双级抬升 |
| **Ctrl + R** | 在键盘模式下，启动当前选中的抬升子状态机 |
| **G** | 刷新裁判系统 UI |
| **X** | 切换键盘底盘方向（Front ↔ Right） |

---

## 三、机械臂控制（`arm_referee.c` — `Arm_Keyboard_Manager`）

### 普通按键

| 按键 | 功能 |
|------|------|
| **F** | 切换到自定义手柄跟随模式（`Arm_Custom_Controller_Follow_Mode`） |
| **Q** | 切换到自动模式，按顺序执行 `A → B → C → A → ...` 的**取矿位置**轨迹 |
| **E** | 切换到自动模式，按顺序执行 `右后 → 右中 → 右前 → 左前 → ...` 的**取矿/存矿**轨迹 |
| **V** | 切换到抬升模式（`Arm_Rising_Mode`，机械臂关节走到抬升姿态） |
| **Z** | **进入/退出紧急存矿模式**（切换开关，进入后按 Q 执行存矿） |

### Ctrl 组合键

| 按键 | 功能 |
|------|------|
| **Ctrl + Q** | 自动模式下，执行当前点位（A/B/C）的**放置**轨迹 |
| **Ctrl + E** | 切换到下一个取矿点位（右后 → 右中 → 右前 → 左前，循环） |

### Z + Q 紧急存矿组合

| 操作 | 功能 |
|------|------|
| **Z** | 开启/关闭紧急存矿模式（切换开关） |
| **Z → E** | 紧急模式下，循环选择存矿目标：**右前 ↔ 左前** |
| **Z → Q** | 按当前选中的位置执行紧急存矿轨迹，**用完自动退出紧急模式** |

> **紧急模式可用位置**：**右前**、**左前**（不包含右中、右后）
>
> **流程**：
> 1. 按 **Z** 进入紧急存矿模式
> 2. 按 **E** 选择存矿目标（右前 ↔ 左前）
> 3. 按 **Q** 执行存矿（机械臂已夹紧矿 → 转到目标位 → 张开 → 下放 → 回位）
> 4. 存矿结束后自动退出紧急模式
>
> *注：普通模式下 E 仍正常循环 4 个取矿位置不受影响。*

## 四、自动轨迹列表（`auto_traj_data.h` / `auto_get_task.cpp`）

按键 **Q** 和 **E** 触发以下预定义机械臂轨迹组：

### Q 键循环（A → B → C 取矿位置）

| 轨迹变量名 | 含义 | 触发方式 |
|------------|------|----------|
| `traj_group_auto_A_step1` | A 点取矿位置轨迹 | Q 键（第1次按Q） |
| `traj_group_auto_A_step2` | A 点放置轨迹 | Ctrl + Q（A 放置） |
| `traj_group_auto_B_step1` | B 点取矿位置轨迹 | Q 键（第2次按Q） |
| `traj_group_auto_B_step2` | B 点放置轨迹 | Ctrl + Q（B 放置） |
| `traj_group_auto_C_step1` | C 点取矿位置轨迹 | Q 键（第3次按Q） |
| `traj_group_auto_C_step2` | C 点放置轨迹 | Ctrl + Q（C 放置） |

### E 键循环（右后 → 右中 → 右前 → 左前）

#### 取矿轨迹（已存在）

| 轨迹变量名 | 含义 | 触发方式 |
|------------|------|----------|
| `traj_back_get` | 右后取矿轨迹 | E 键（第1次按E） |
| `statsh_get` | 右中取矿轨迹 | E 键（第2次按E） |
| `statsh_put_L_A` | 右前取矿轨迹 | E 键（第3次按E） |
| `statsh_get_front_L` | 左前取矿轨迹 | E 键（第4次按E） |

#### 紧急存矿轨迹（新增）

| 轨迹变量名 | 对应位置 | 说明 |
|------------|---------|------|
| `emerency_auto_stash_R_B` | 右后 | 已夹紧矿→转到右后→张开→下放J5→回位 |
| `emerency_auto_stash_R_M` | 右中 | 已夹紧矿→转到右中→张开→下放J5→回位 |
| `emerency_auto_stash_R_F` | 右前 | 已夹紧矿→转到右前→张开→下放J5→回位 |
| `emerency_auto_stash_L_F` | 左前 | 已夹紧矿→转到左前→张开→下放J5→回位 |

> 紧急存矿轨迹共 **10 个路径点**，总耗时约 **10 秒**。
> 运动序列：起始(已夹紧) → 转到目标J1 → 调整J2/J3 → 张开夹具 → 下放J5(-0.2→-1.2→-1.5) → 回位 → 稳定

## 六、自动轨迹任务说明（`auto_get_task.cpp`）

- 任务初始化时默认加载 `traj_group_auto_A_step1` 轨迹组。
- 每次通过 `Q` 或 `E` 按键触发时，调用 `Auto_Switch_Group()` 切换到对应的轨迹组并重置计时器。
- 轨迹按时间顺序逐段执行，每 5ms 更新一次关节目标位置。
- 轨迹执行完毕后自动停止定时器。
- 可通过 `TRAJ_DEBUG` 宏（`arm_debug.h`）切换为调试轨迹组 `debug_traj`。
