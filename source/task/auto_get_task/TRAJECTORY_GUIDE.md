## 2. 轨迹数据结构

### 2.1 单点结构

```cpp
struct target_point_t {
    float target_joint_radian;  // 目标弧度 (rad)
    float velocity;             // 运动速度 (rad/s)
};
```

### 2.2 轨迹点结构

```cpp
struct traj_group_point_t {
    target_point_t q[6];           // 6个关节的目标点
    uint32_t time;                 // 本段持续时间 (ms)
    gripper_control_mode_t gripper_ctrl;  // 夹爪控制模式
};
```

### 2.3 关节顺序

| 索引 | 关节 | 说明 |
|------|------|------|
| 0 | J1 | 底座旋转 (偏航) |
| 1 | J2 | 大臂 (俯仰) |
| 2 | J3 | 小臂 (俯仰) |
| 3 | J4 | 腕部旋转 (滚转) |
| 4 | J5 | 腕部俯仰 |
| 5 | J6 | 末端旋转 (滚转) |

### 2.4 夹爪模式

| 模式 | 说明 |
|------|------|
| `GRIPPER_OPEN_MODE` | 夹爪打开 |
| `GRIPPER_CLOSE_MODE` | 夹爪关闭 |
| `GRIPPER_SPECI_MODE` | 夹爪特殊位置 |

### 3.2 取矿轨迹详解

#### 3.2.1 traj_group_A (取矿方式A)

**用途**: 斜前方取矿

| 步骤 | J1 | J2 | J3 | J4 | J5 | J6 | 时间 | 夹爪 |
|------|----|----|----|----|----|----|------|------|
| 1 | 0 | 0 | 0.2 | 0 | 0 | 0 | 5000ms | 打开 |
| 2 | 0 | 0.7 | 0.85 | 0 | 0 | π | 5000ms | 打开 |
| 3 | 0 | 0.7 | 0.7 | 0 | -0.5 | π | 2000ms | **关闭** |
| 4 | 0 | 0 | 0.7 | 0 | 0 | 0 | 1000ms | 关闭 |
| 5 | 0 | 0 | 0.2 | 0 | 0 | 0 | 2000ms | 关闭 |

### 5.2 代码流程

```cpp
// 1. 键盘触发命令
auto_key_cmd_exec(CMD_AUTO_GET_A_POS);

// 2. 命令提交到队列
cmd_req = CMD_AUTO_GET_A_POS;

// 3. 任务主循环处理
while (true) {
    if (cmd_req != CMD_NONE) {
        switch (cmd_req) {
            case CMD_AUTO_GET_A_POS:
                Auto_Switch_Group(traj_group_auto_A_step1, ...);
                break;
        }
    }
    
    // 4. 更新轨迹
    traj_exec.update(auto_traj_idx, Target_Point);
    
    // 5. 检查完成
    if (traj_exec.is_finished()) {
        osTimerStop(auto_traj_timer_id);
    }
    
    osDelay(5);
}
```

## 6. 添加新轨迹的详细步骤

### 步骤1: 确定轨迹需求

在添加轨迹前，需要明确：

| 需求项 | 说明 |
|--------|------|
| 轨迹用途 | 取矿/存矿/其他 |
| 目标位置 | 哪个方向、多远 |
| 关节数量 | 需要几个关节运动 |
| 夹爪动作 | 何时打开/关闭 |
| 时间要求 | 每步多长时间 |

---

### 步骤2: 设计轨迹点

#### 6.2.1 关节角度参考

| 关节 | 最小值 | 最大值 | 常用值 |
|------|--------|--------|--------|
| J1 | -2.0 | 2.0 | 0, ±0.73, ±(π/2+0.1), ±2.35 |
| J2 | -2.5 | 2.5 | 0, 0.4, 0.7, 1.0, 1.25 |
| J3 | 3.0* | 3.0* | 0.2, 0.5, 0.7, 1.0, 1.5 |
| J4 | -3.2 | 3.2 | 0, 0.87, 0.9 |
| J5 | -2.5 | 2.5 | -1.5, -0.5, 0, 0.6 |
| J6 | -1.5 | 1.5 | 0, π, π-0.9 |

*注: J3的限制值可能有误，实际使用0-2.0

#### 6.2.2 速度参考

| 速度等级 | 值 (rad/s) | 适用场景 |
|----------|-----------|----------|
| 慢速 | 0.5 | 精确定位 |
| 中速 | 1.0 | 正常运动 |
| 快速 | 2.0 | 快速移动 |
| 极快 | 3.0 | 紧急动作 |

#### 6.3.3 时间参考

| 时间 | 适用场景 |
|------|----------|
| 500ms | 快速切换 |
| 1000ms | 正常动作 |
| 1500ms | 稳定过渡 |
| 2000ms | 等待稳定 |
| 3000ms+ | 长距离移动 |

```cpp

    {
        {
            // {目标弧度, 速度} × 6个关节
```

## 7. 轨迹设计技巧

### 7.1 安全原则

```
┌─────────────────────────────────────────────────────────────┐
│                      轨迹设计安全原则                        │
├─────────────────────────────────────────────────────────────┤
│ 1. 避免关节极限: 不要使用最大/最小位置                        │
│ 2. 避免碰撞: 注意关节之间的相对位置                           │
│ 3. 速度渐变: 快速运动后要有缓冲                              │
│ 4. 夹爪时机: 确保到位后再开合                                │
│ 5. 回位保护: 每个轨迹都要有回位步骤                          │
└─────────────────────────────────────────────────────────────┘
```

### 7.2 优化建议

| 优化项 | 建议 |
|--------|------|
| 时间 | 尽量缩短总时间，但要保证稳定 |
| 速度 | 快速移动用高速，精确定位用低速 |
| 路径 | 选择最短路径，避免多余动作 |
| 夹爪 | 开合时机要准确，避免碰撞 |

### 7.3 常用轨迹模式

#### 模式1: 取矿轨迹

```
准备 → 接近 → 下降 → 夹取 → 抬起 → 回位
```

#### 模式2: 存矿轨迹

```
准备 → 旋转到仓口 → 下降 → 打开夹爪 → 退出 → 抬起 → 回位
```

#### 模式3: 紧急存矿轨迹

```
保持夹取 → 旋转到仓口 → 下降 → 打开夹爪 → 下放 → 退出 → 抬起 → 回位
```
