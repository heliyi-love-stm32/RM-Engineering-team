# Engineer_26 机器人电控技术方案

**项目**：Engineer_26 / RMtextH7  
**对象**：工程机器人电控系统  
**主控**：STM32H723VGTx，Cortex-M7，480 MHz（以 `RMtextH7.ioc` 和链接脚本为最终依据）  
**软件基线**：当前工作区源码；历史说明与实际实现不一致时，以源码和实测为准  
**文档状态**：方案基线，待硬件参数、总线波特率和实测数据补齐

> 本方案依据工程根目录说明、`engineer_documents/`、`source/` 下模块文档及当前 C/C++ 源码整理。第三方 HAL、CMSIS 和 FreeRTOS 原厂说明不作为本项目功能定义依据。

## 1. 建设目标与范围

### 1.1 建设目标

构建一套面向 RoboMaster 工程机器人的实时电控系统，完成以下功能：

- 四轮麦克纳姆底盘的全向运动、航向稳定和功率受限控制；
- 抬升机构的 3508 速度控制、DM 电机姿态控制和外部 IMU 补偿；
- 六自由度机械臂的手动跟随、冻结、预设姿态、自动轨迹和夹爪控制；
- DBUS 遥控器、裁判系统键盘、自定义控制器、上位机等多输入源接入；
- 裁判系统、超级电容和视觉/雷达链路的数据采集与状态上报；
- 电机离线、DM 故障、控制器失联和异常模式下的保护、报警与恢复。

### 1.2 安全边界

电控软件负责控制指令生成、通信状态监测和输出限幅，不替代电源硬件急停、保险、驱动器硬件保护和机械限位。下列措施必须由整机设计确认：

1. 电池、保险、总电源继电器和急停回路；
2. 电机驱动器过压、欠压、过流、过温和堵转保护；
3. 机械臂关节机械限位、软限位和碰撞区域；
4. CAN 收发器、终端电阻、接地和线束防反接；
5. 上电默认零输出、通信丢失后的安全状态及人工复位条件。

## 2. 系统总体架构

系统采用 BSP、功能模块和应用任务三层结构，并由 STM32 HAL 和 FreeRTOS 提供基础运行环境。

```text
传感器/操控设备
  DBUS、键盘鼠标、控制器、裁判系统、BMI088、DM-IMU、上位机
             │ UART/SPI/CAN
             ▼
硬件抽象层 HAL
  FDCAN、UART/DMA、SPI、TIM/PWM、GPIO、CRC
             ▼
BSP
  CAN 消息注册与中断分发、UART Hook、BMI088、DWT、蜂鸣器
             ▼
功能模块
  DJI/DM 电机、DBUS、IMU、PID、麦轮、功率控制、裁判系统、上位机、超级电容
             ▼
应用任务
  底盘、机械臂、遥控器、裁判系统、IMU、轨迹、看门狗
             ▼
执行器
  DJI 3508、DM 电机、夹爪、蜂鸣器
```

### 2.1 数据交换原则

- CAN 接收采用“设备注册 + ID 查找 + 中断更新”的方式；任务周期内刷新并解析电机反馈。
- UART 采用 DMA/空闲线接收和 Hook 回调；UART7、USART1 使用 shadow buffer 避免 DMA 重启时覆盖待解析数据。
- 任务之间目前使用全局状态快照、共享结构体和 RTOS 线程标志。后续应将关键共享数据统一为版本号或双缓冲快照，避免多字段结构体被并发读写时出现半更新。
- 所有运动输出均应经过模式状态、在线状态、限位、限幅和功率分配后再发送。

### 3.1 电机组成与选型

本工程实际使用两类电机，控制策略不同，不能混用驱动协议。

| 电机类别 | 数量 | 主要安装位置 | 反馈内容 | 软件控制方式 |
|---|---:|---|---|---|
| DJI 3508 | 4 | 麦克纳姆底盘四个车轮 | 角度、转速、电流、温度 | CAN 反馈闭环，外部轮速 PID 输出电流 |
| DJI 3508 | 2 | 抬升机构左右驱动 | 角度、转速、电流、温度 | CAN 反馈速度 PID，左右目标速度相反 |
| DM 达妙电机 | 6 | 机械臂 J1~J6 | 角度、速度、力矩、温度、错误码 | 位置/速度目标，或由软件双环生成 MIT 力矩 |
| DM 达妙电机 | 2 | 抬升机构左右姿态关节 | 角度、速度、力矩、错误码 | 位置误差 + 速度反馈 + 力矩前馈 |
| DM 达妙电机 | 1 | 末端夹爪 | 角度、速度、力矩、错误码 | 开、关和特殊位置的 PosSpeed 控制 |

因此，整机当前电机总数为 14 台：6 台 DJI 3508、9 台 DM 电机，其中 8 台参与底盘/抬升/机械臂，1 台为夹爪。电机的具体供应商型号、减速比、额定电压、峰值电流和机械安装方式不在当前工程文件中，必须由采购清单和机械图纸补齐。

DM 电机驱动层支持三种帧模式：

- `MIT_MODE`：8 字节打包位置、速度、Kp、Kd 和力矩；
- `POS_MODE`：8 字节发送浮点位置和浮点速度；
- `SPD_MODE`：4 字节发送浮点速度。

当前机械臂关节主要由 `Joint_Motor_PosSpeed_Ctrl()` 走位置/速度控制；抬升 DM 在 `Rising_Motor_SendControl_DM()` 中根据位置环和速度环计算力矩，再通过 MIT 帧发送。DJI 3508 则使用 CAN 经典帧统一发送多个 16 位电流值。

### 3.2 线路连接方案

下面是电控实施时应采用的连接拓扑。CAN 节点的物理线束应使用 CANH/CANL 双绞线，所有节点共地，支路尽量短，干线两端配置 120 Ω 终端电阻。电机动力线不能与 CAN 信号线共用细线或直接并接。

```text
电池/电源分配板
  ├── 主控板 DC/DC ── STM32H723 控制板
  ├── DJI 电机电源 ── 3508 底盘四轮 + 抬升两路
  ├── DM 电机电源 ── 机械臂 J1~J6 + 抬升 DM 左右 + 夹爪 DM
  └── 外设电源 ───── DM-IMU、遥控接收、裁判系统/上位机

STM32 控制板
  ├── CAN1 收发器 ── CAN1 总线 ── DJI 3508 x6
  ├── CAN2 收发器 ── CAN2 总线 ── 部分 DM 关节 + DM 夹爪
  ├── CAN3 收发器 ── CAN3 总线 ── 其余 DM 关节 + 抬升 DM x2 + DM-IMU
  ├── UART5 ──────── DBUS 遥控器接收端
  ├── UART7 ──────── 自定义控制器/图传控制链路
  ├── USART1 ─────── 裁判系统与 UI 链路
  ├── SPI2 ────────── BMI088（实际片选和引脚以 IOC/原理图为准）
  └── TIM PWM ─────── BMI088 加热与蜂鸣器
```

### 3.3 推荐线材和连接要求

| 连接对象 | 推荐线材/连接 | 设计要求 |
|---|---|---|
| CAN 总线 | 120 Ω 特性阻抗 CAN 双绞线，CANH/CANL 成对走线 | 总线两端各 120 Ω；支线短；控制板与电机共地 |
| DJI 3508 动力 | 电机原配三相动力线或等效耐弯折硅胶线 | 相序和方向逐台确认；动力线与信号线分束 |
| DM 电机动力 | 按电机额定电流选用多芯动力线，带锁紧插头 | 电源正负、CANH/CANL、地线标识清楚；禁止带电插拔 |
| UART/DBUS | 3.3 V TTL 信号线，信号线与地线成对 | 先确认接收器电平；不能直接接 RS-232 电平 |
| SPI/BMI088 | 短距离屏蔽或紧耦合排线 | 3.3 V 供电，SCK/MOSI/MISO/CS 分别核对，地线完整 |
| PWM/蜂鸣器 | PWM 信号线 + 地线；负载电源单独供给 | 蜂鸣器和加热负载的电流回路不能经 MCU GPIO |
| 电源 | 电池到分配板使用大电流软硅线，分支加保险 | 保险丝、反接保护、急停和 DC/DC 输入范围必须按实测定型 |

当前仓库没有给出线径、接插件型号、收发器型号、终端电阻位置和电源板原理图，因此上表是工程实施要求，不是已确认的采购型号。正式接线前应输出一张带插头编号、线色、线号和端子定义的线束表，并用万用表、示波器和 CAN 分析仪逐条确认。

## 4. 实时任务设计

| 任务/服务 | 周期或触发 | 主要职责 |
|---|---:|---|
| `jointFollowAngle` | 1 ms | 刷新六关节反馈、管理关节状态机、生成关节目标、下发 DM 控制 |
| `Chassis_Task` | 2 ms | 输入仲裁、模式解析、底盘运动学、抬升状态机和输出调度 |
| `IMU_TempCtrl` | 约 1 ms | BMI088 读取、恒温、零偏标定和 Mahony 姿态解算 |
| `IMU_Task` | 当前循环 1 ms | 外部 DM-IMU 刷新；欧拉角低频请求、陀螺仪高频请求 |
| `Referee_Task` | 2 ms | 裁判系统、自定义控制器、键盘边沿和 UI 服务 |
| `Remoter_Task` | 约 1 ms | DBUS 初始化、帧刷新和遥控器数据解析 |
| `Trajectory/Auto` | 轨迹定时器约 5 ms | 轨迹段推进、目标点发布和结束处理 |
| `Watchdog_Task` | 启用时约 1 ms | 电机在线、DM 状态、遥控器和报警/保护；禁用时仍可能执行 DM 自动使能 |

控制链路应遵循：**采集反馈 → 解析输入 → 解析模式 → 更新状态机 → 计算目标 → 闭环控制 → 功率限幅 → 发送输出 → 发布诊断**。

## 5. 输入与通信协议

### 5.1 DBUS 遥控器

UART5 接收固定 18 字节帧，解析为 4 个通道、2 个拨码、鼠标三轴、鼠标按键和键盘位域。通道范围基线为 ±660，近零区间做死区处理，异常范围触发结构体清零。

DBUS 是默认控制源。当前底盘模式由 `sw2` 推导：PowerOff、Normal、Rising；`sw1` 还参与抬升/下楼等动作条件。遥控器无变化超时不得直接等同于链路失联，必须同时结合有效帧计数、串口错误和通道状态判断。

### 5.2 键盘与控制源

当前工程默认键盘数据源为裁判系统键盘（`USE_REMOTER_KEYBOARD=0` 的配置基线），也保留从 DBUS 键盘位域读取的兼容路径。

当前源码的功能键应以 `referee_keyboard.c` 为准：

- B：DBUS/Keyboard 控制源切换；
- C：键盘模式下设置 Normal；
- R：请求 Rising；
- X：切换键盘运动方向；
- WASD：平移；Shift：速度比例调整；Ctrl：屏蔽普通平移并保留组合功能；鼠标：航向输入。

历史“C 切换 Normal/Rising”的说明已过时，方案和操作手册应统一按源码更新。

### 5.3 裁判系统和自定义控制器

裁判系统采用帧头 CRC8、帧体 CRC16 校验，并提供比赛状态、机器人状态、底盘功率热量和 UI 数据。UART7 用于自定义控制器数据接收。

自定义控制器的“26 字节”描述与代码访问 `CtrllerData[26]` 存在边界风险。正式版本必须固定：帧头、载荷长度、数组长度、字节序、CRC 覆盖范围和丢帧策略，并增加长度检查后再转换为六关节目标。

### 5.4 外部 DM-IMU

`IMU_Task` 周期刷新 IMU 快照，将角度转换为弧度，并交替请求：

- 欧拉角，用于绝对角校正和抬升 Pitch 补偿；
- 角速度，用于航向闭环的快速反馈。

快照包含 Pitch、Yaw、Roll 及三轴角速度，使用 `IMU_data_time` 表示更新时间。控制器在时间戳无效、数据超时或跳变超限时必须降级为安全输出。

### 5.5 上位机与超级电容

上位机模块预留视觉目标、雷达、Twist 速度指令和机器人状态通信；正式协议需补齐帧格式、频率、坐标系、时间戳和校验。

超级电容模块通过 CAN 读取输入电压、电容电压、输入电流和目标功率等量，当前文档描述的数据缩放为原始 `uint16_t / 100`。电量低于约 5% 时进入功率受限策略；该阈值、迟滞和恢复条件必须通过实测固化。

## 6. 底盘控制方案

### 6.1 运动学与轮速闭环

底盘输入统一转换为机器人坐标系运动向量 $(v_x, v_y, \omega_z)$，经麦克纳姆逆运动学得到四轮目标速度：

$$
\begin{aligned}
\omega_{LF} &= v_x + v_y + k_r\omega_z \\
\omega_{LB} &= v_x - v_y + k_r\omega_z \\
\omega_{RB} &= -v_x - v_y - k_r\omega_z \\
\omega_{RF} &= -v_x + v_y - k_r\omega_z
\end{aligned}
$$

每个 DJI 3508 使用独立轮速 PID，反馈来自 CAN 电机转速，输出为电流指令。输出经过低通滤波、加减速斜坡和功率分配后，以 CAN 帧发送。

### 6.2 航向闭环

航向控制采用角度估计、目标角生成和速度内环：

1. 外部 IMU 角速度积分，欧拉角进行渐进校正；
2. DBUS 或鼠标输入生成目标角速度，并形成保持目标角；
3. 位置误差生成目标角速度，速度 PID 输出底盘旋转量；
4. 输入释放时捕获当前角度，避免残余角误差导致继续旋转；
5. IMU 无效时禁止闭环旋转输出并发布诊断状态。

### 6.3 底盘状态机

- **PowerOff**：所有底盘和抬升 3508 输出清零，DM 机构回到定义的安全姿态或停止状态；
- **Normal**：四轮全向运动，抬升 3508 停止，抬升 DM 保持普通姿态；
- **Rising**：四轮运动与抬升 3508 并行，抬升 DM 根据 IMU Pitch 进行姿态补偿；
- **Downstairs**：抬升 3508 停止，DM 运动到下楼预设姿态；
- **自动上升序列**：通过边沿或按键触发，依次经过 Lifting、Transition、Driving，以及双抬升相关保持阶段，所有阶段使用无符号 tick 差值处理计数器回绕。

模式切换时应重置相关 PID、滤波器、目标斜坡和状态机请求，避免积分残留与目标突变。

## 7. 抬升机构控制方案

抬升机构由两路 DJI 3508 提供速度驱动，两路 DM 电机提供姿态/位置调节。

- 3508：`ch2` 映射为左右相反的目标速度，正向大于阈值时可触发最大速度策略；采用速度反馈 PID。
- DM：根据左右对称的目标角进行位置误差、目标速度和力矩计算，加入重力/姿态相关前馈，并使用力矩低通滤波。
- IMU 补偿：Rising 模式将 Pitch 误差经外环 PID 转为目标角偏移，目标角再经过模式切换斜坡限制，避免抬升机构突然动作。
- 安全：DM 电机反馈解析错误码，位置、速度、力矩和温度均必须限幅；目标角度必须叠加机械工作区和零点校准限制。

需要在参数表中固定：零点、正负方向、最大角度、速度/力矩上限、Pitch 目标、外环 PID、位置/速度 PID、前馈和模式切换斜坡。

## 8. 六自由度机械臂与夹爪

### 8.1 机械结构与电机连接

机械臂由 J1~J6 六个旋转关节和一个末端夹爪组成。六个关节均使用 DM 电机，夹爪也使用一个 DM 电机；电机只负责关节执行，控制器输入、轨迹和状态机由 STM32 完成。

当前代码已确认的连接关系如下：

| 对象 | 数量 | 当前代码配置 | 说明 |
|---|---:|---|---|
| J1~J6 DM 关节 | 6 | 端口由 `can_port_map[6]` 决定，ID 按关节索引生成 | 最终 CAN2/CAN3 分配需以 `can_port_map` 和实物 ID 表为准 |
| 夹爪 DM 电机 | 1 | CAN2，控制 ID 0x07，反馈 ID 0x17 | `Gripper_Open/Close/Speci` 发送位置/速度目标 |
| 关节反馈 | 6 | 电机反馈帧注册到 CAN 消息链表 | 由 `Motor_DM_Refresh()` 解码角度、速度、力矩和错误码 |

每个 DM 电机至少需要动力正负、CANH、CANL和信号地；电机电源回路与主控 3.3 V 逻辑电源隔离。多个 DM 电机挂在同一条 CAN 总线时，必须保证 ID 唯一，不能只靠软件数组下标区分设备。

### 8.2 机械臂代码执行流程

机械臂上电后的软件流程为：

1. `jointFollowAngle` 创建并初始化六个 `DM_motor_t`，设置每个关节的 CAN 控制 ID、反馈 ID、位置/速度/力矩范围和总线端口；
2. 初始化 `Target_Point[6]`，设置初始关节目标和默认速度；
3. 初始化夹爪电机并等待系统稳定；
4. 根据调试配置使能或失能全部关节和夹爪电机；
5. 每 1 ms 发送关节目标、刷新六个关节和夹爪反馈、更新当前弧度，并调用 `Joint_Control_Mode_Manager()`；
6. 状态机根据当前模式生成新的 `Target_Point[6]`，下一周期继续执行。

关节控制发送具有固定的错峰顺序：J2/J5、J3/J1、J4、J6，每组之间延时 1 ms，用于降低同一时刻的 CAN 发送压力和机械冲击。该顺序不是机械臂运动学规划，实际运动安全仍由目标角度、速度、软限位和机械限位共同保证。

### 8.3 控制结构

机械臂执行任务每 1 ms 刷新 DM 电机，所有控制模式最终输出统一的 `Target_Point[6]`，再由关节执行层完成位置/速度控制。推荐模式如下：

- 启动/安全：输出受限，等待反馈和零位有效；
- Custom Controller Follow：解析 UART7 控制器数据，完成方向、偏置、弧度映射和关节限位；
- Frozen：停止目标变化，保持安全位置；
- Rising：移动至上台阶前的预设收拢姿态；
- Auto：按轨迹段执行取放矿等动作；
- Zero/Reset：按标定策略回零或恢复默认姿态。

### 8.4 轨迹执行

当前实现以关节空间轨迹段为主。单个节点至少包含六关节角度、六关节速度、持续时间和夹爪动作。轨迹控制器约每 5 ms 推进一次段索引，关节执行任务约每 1 ms 下发电机指令；段内目前以目标段方式执行，不应描述为固定 656 个采样点插值轨迹。

轨迹验收必须分为：单段空载、低速逐段、完整空载、带载逐段、完整带载和异常中断恢复。每次记录关节误差、最大速度、夹爪时序、完成时间和电机错误码。

历史资料中的轨迹名称、段数和总时长存在差异，例如 `statsh_put_L` 的节点合计与指南描述不一致；按键到实际轨迹变量的映射应以当前按键管理器和轨迹数据表联合确认。

## 9. 功率管理与超级电容

### 9.1 功率估算

底盘功率模块根据电流指令和电机速度估算单电机功率，并按底盘前轮、后轮和抬升机构分组分配预算。模型参数包括扭矩系数、速度项、扭矩项、静态项和全局缩放。静态项不得在静止状态虚增功率需求。

### 9.2 限功流程

1. 读取裁判系统底盘功率上限、实际功率和缓冲能量；
2. 与用户最大功率取较小值，叠加安全比例和安全余量；
3. 估算各组功率需求并计算缩放因子；
4. 快速降低输出，缓慢恢复输出，避免功率振荡；
5. 对电流输出执行上升/下降斜坡，再进行最终限幅；
6. 发布估算功率、限功比例和各组状态用于调试。

当前配置说明了底盘默认用户功率上限和限功开关，但正式发布前必须以实测功率和比赛规则校准。

### 9.3 超级电容策略

超级电容用于短时功率补偿和能量缓冲。需要明确电容状态机：正常、功率受限、低电量、充电恢复和故障。低电量时优先保证控制器和通信稳定，禁止因电容补偿造成持续过流。超级电容协议实现存在文档签名不一致和结构清零风险，纳入代码整改清单。

## 10. 故障安全与诊断

### 10.1 看门狗策略

看门狗监测 CAN 反馈计数变化、DM 错误码和遥控器状态：

- 3508 无反馈超过约 500 ms：标记离线并蜂鸣器分级报警；
- DM 在线但失能：约 200 ms 周期重使能；错误码按清错、重使能策略处理；
- 遥控器无有效输入或无变化超过配置阈值：请求底盘强制 PowerOff；
- 所有恢复动作必须受重试次数、错误类型和人工复位条件约束。

重要基线：当前 `WATCHDOG_ENABLE_DEFAULT` 为 0，意味着报警和强制掉电保护默认关闭；比赛固件必须确认是否改为 1，并在上电诊断中显示当前状态。DM 自动使能路径与总开关并不完全一致，需单独评审。

### 10.2 分级安全状态

建议统一为：

1. **正常**：输入、反馈和功率均有效；
2. **降级**：单路传感器异常，限制对应机构输出；
3. **停止**：控制输入或电机反馈超时，清零相关输出；
4. **锁定**：严重过流、过温、总线故障或重复恢复失败，等待人工复位。

每个安全状态应有进入条件、退出条件、输出策略、蜂鸣器编码和遥测字段，不能只依赖日志或调试串口。

## 11. 参数、标定与版本管理

以下参数必须从“代码常量”升级为带单位、来源和版本号的参数表：

- CAN 波特率、ID、发送周期和总线负载；
- DJI/DM 电机型号、方向、零点、反馈缩放和控制上限；
- 麦轮几何尺寸、运动学比例、轮速 PID 和低通系数；
- 航向 IMU 安装方向、角速度极性、输入死区和串级 PID；
- 抬升 DM 零点、Pitch 补偿 PID、前馈和机械限位；
- 六关节方向、偏置、角度/速度限位和机械干涉区；
- 裁判系统、控制器、上位机和超级电容帧长度及超时；
- 功率模型、限功安全系数、恢复斜率和低电量阈值；
- 看门狗默认开关、超时阈值、报警频率和自动恢复次数。

标定顺序建议为：空载通信 → 单电机方向 → 反馈零点 → 单轴低速 → PID → 功率模型 → 子系统联调 → 带载轨迹 → 整机场景。

## 附录 A：方案基线结论

本工程的核心技术路线是：**STM32H723 高性能单片机 + FreeRTOS 多任务调度 + 三路 FDCAN 电机网络 + UART/SPI 多源采集 + 轮速/位置/速度/航向多闭环控制 + 功率管理 + 分级故障安全**。

其中，底盘控制、抬升闭环、六关节机械臂和轨迹执行已具备较完整的软件实现；硬件电气参数、协议完整定义、实测验收数据和若干历史文档差异仍是正式定版前的主要工作。方案评审应优先围绕这些可验证项闭环，而不是继续扩展未完成的功能描述。
