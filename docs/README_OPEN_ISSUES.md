# 重装双板开放问题与确认清单

本文件将“代码已实现”与“可安全上车”分开。未确认项不会自动成为发射许可条件。

## 已确定

| 项目 | 依据 | 当前实现 |
| --- | --- | --- |
| 主控与 CAN 数量 | DM-MC-Board02 使用说明书 | STM32H723，三个 FDCAN 外设均在板二 `.ioc` 中配置。 |
| SBUS 帧制式 | DM-MC-Board02 使用说明书 | UART5 配为 100 kbaud、8E2；解析标准 25 字节 SBUS 帧。 |
| FDCAN3 角色 | 本次双板任务 | 只承载 `0x301`、`0x302` 板间帧。 |
| 发射安全上限 | 2027 规则 | 代码目标限制在 12–14 m/s，硬上限为 16.5 m/s。 |
| 发射闭锁 | 本次双板任务 | 板间、裁判、热量、许可弹量和看门狗任一失效即闭锁。 |

## 合理但必须验证的假设

| 项目 | 当前假设 | 确认负责人 | 验收方式 |
| --- | --- | --- | --- |
| FDCAN1 ID | DJI 1–4 对应 `0x201`–`0x204`，组帧 `0x200` | 云台/发射电控 | 单机上电抓帧、方向测试。 |
| DM4310 ID | 从机 `0x10`、主机反馈 `0x11` | 云台/发射电控 | 达妙上位机与隔离 CAN 台架确认。 |
| 摩擦轮传动 | 默认反馈到轮轴比为 1.0，M3508 19.203 仅保留为显式配置资料 | 发射机械 + 电控 | 实测电机 rpm、轮速和弹速后写入 `heavy_config.h`。 |
| pitch 范围 | 暂定 -0.5 到 +0.5 rad | 云台机械 | 建零位后缓慢扫角并设置硬/软限位。 |
| PID/电流 | 配置为保守初值 | 发射电控 | 空载、带轮、带弹逐级整定并记录。 |

## 完全未知或未纳入旧协议

| 问题 | 风险 | 当前保护 | 需要谁确认 |
| --- | --- | --- | --- |
| 2027 裁判协议中的 42 mm 许可弹量字段 | 错字段会错误放行发射 | `allowed_42mm_rounds` 默认 0；仅临时接受板一字段 | 规则/裁判系统负责人。 |
| SBUS 物理路由 | 使用说明书指出 PC02 反相输入；继承 `.ioc` 是 UART5_RX/PD2，PC2 当前复用 SPI2 | 仅改 UART 帧格式，不猜测引脚；SBUS 不参与发射许可 | 硬件负责人，提供原理图/实板测量。 |
| 42 mm 实际热量/冷却字段版本 | 旧协议结构不一定等同 2027 | 热量或上限为 0 时不放行 | 裁判系统负责人。 |
| 英雄工程云台源硬件 | 任务描述与实际源代码的 yaw/pitch 电机类型相反 | 未直接复制其硬件层 | 云台/发射电控负责人。 |
| 供弹控制归属和授权条件 | 板二不含拨弹控制 | 板二只报告 `fire_permitted`，不驱动供弹 | 机械、软件与比赛策略负责人。 |

## 上车前必须关闭的项

1. 确认并记录 SBUS 反相器、实际 MCU 引脚和 UART5 接收方式。
2. 确认 FDCAN1/2/3 接线、120 Ω 终端与所有 ID 无冲突。
3. 完成 pitch 零位和摩擦轮方向/传动比标定。
4. 把官方 2027 裁判协议中的许可、热量和供电字段接入后，删除临时许可字段或明确其唯一数据源。
5. 在测速仪上证明发射全工作点均不超过 16.5 m/s，并保留测试记录。
